eino-data-agent 架构全景

Text-to-SQL Agent — Go + CloudWeGo Eino + DeepSeek + DashScope

用户自然语言提问 → 中文分词抽取关键词 → 向量/全文检索召回字段和取值 → LLM 筛选表和指标 → 生成 SQL → MySQL EXPLAIN 验证 → 执行并返回结果。 全程通过 SSE 推送进度和中间数据。
